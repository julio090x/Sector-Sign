# Sector Sign

Dos aplicaciones para cartelería digital: **Centro de Mando** y **Reproductor**, con servidor PHP/MySQL independiente para aaPanel.

Repositorio del proyecto, separado de SectorPay e Inventario Pro 360. Importación de fuentes y verificación de compilación en curso; consulte los resultados de Actions antes de instalar.

## Seguridad

No subir configuraciones reales, contraseñas, claves de firma, tokens, bases de datos del negocio, anuncios privados ni respaldos. Las APK de evaluación usan firma de prueba, no una clave de producción.

## Versión

Base de trabajo: 0.6.0. Actualización de dispositivos y programación múltiple: 0.7.0.
